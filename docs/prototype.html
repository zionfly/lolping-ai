方案要点

  • 新开一个 AI 轮盘，不改原有的信号和表情。沿用 emote wheel 的做法给 WheelKind 加一个 'ai'，hook-helper 多一个触发键（默认 Shift，可改），这样 Alt 和 Ctrl 轮盘的行为都不变。
  • 在 main 进程加一个 runner 模块（src/main/agentRunner.ts）：spawn('ssh', [host, 'claude', '-p', ...])，prompt 和图片通过 stdin 或 scp 传过去，不拼 shell 字符串。--output-format stream-json 让卡片能流式显示进度。超时、取消、同时只跑 N 个都放在纯逻辑模块里，方便测试。
  • 上下文抓取（src/main/contextCapture.ts）：desktopCapturer 截指针所在显示器，裁掉指针周围 1200×800；用 osascript 取前台 App 和窗口标题；选中文字靠模拟 ⌘C，读完再把剪贴板还原。需要 macOS 的“屏幕录制”权限，设置窗口里像辅助功能那样引导用户开启。
  • 开发机侧的配置：在 ~/notes 放一个 CLAUDE.md / AGENTS.md，写明笔记格式、回复口吻和禁区（例如“只起草，不发送，不改仓库”）。Claude 用 --allowedTools "Read,Grep,Glob,Edit(~/notes/**)" 限死能动的范围，Codex 用 --sandbox workspace-write。
  • 结果卡片挂在 overlay 窗口里。overlay 现在是点击穿透的，只在卡片的矩形区域内打开 setIgnoreMouseEvents(false)，鼠标离开后恢复穿透。
  • 隐私：截图和文字只发到你自己配的那台开发机，再由它调用 Claude 或 Codex 的 API。设置里写清楚，并且可以把截图关掉，只发文字。

分阶段

  1. P0，一天，不改 lolPing：本地放一个 lolping-ai 脚本，用 macOS 快捷键（Raycast / Hammerspoon）触发，流程是截图 + 剪贴板 → ssh devbox claude -p → 通知加剪贴板。先确认链路、权限和 prompt 好不好用。
  2. P1，fork lolPing：加 AI 轮盘、runner、结果卡片和 Settings → AI 页，本地 npm run dev 跑起来，打一个自用的 dmg。
  3. P2：笔记同步回本机（Obsidian 或飞书文档），追问时保留会话（claude -r），起草回复后接飞书直接发送，但每次发送前都要你确认。
